Library Management System:

Description:
A desktop application for managing books using Python, PyQt6 and MySQL.

Features
- Show Books
- Search Books
- Add Books
- Delete Books

Technologies
- Python
- PyQt6
- MySQL
- mysql-connector-python

Installation
1. Install MySQL
2. Import LIBRARY_MANAGEMENT_SYSTEM.sql
3. Run frontend.exe
